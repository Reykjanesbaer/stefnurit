Body text never drops below 15px: the type scale is fluid between a readable
floor and the size the original used at full width, rather than shrinking in
proportion to the widget.

The column tree needs about 1400px — five columns wide enough that
"Upplýsingaöryggisstefna" sits on one line. Chromium has no Icelandic
hyphenation patterns, so a narrower column would have to break compounds
mid-syllable. Below that width the layout stacks instead, keeping to a readable
measure with the rail in its own gutter.
